# Data Availability Statement Patterns

Use these patterns to draft transparent, submission-ready data statements. Replace bracketed fields with verified information.

## 1. Public Repository (Standard)
```text
The [raw/processed/source] data supporting the findings of this study are available in [Repository] under accession [ID] or at [DOI]. The deposited record contains [brief contents: e.g., raw measurements, processed tables].
```

## 2. Mixed Generated and Reused Data
```text
Data generated in this study are available in [Repository] under [ID]. Public datasets reused in the analysis were obtained from [Source 1, DOI/Accession] and [Source 2, DOI/Accession]. Source data for [figures/tables] are provided in [Location].
```

## 3. Data in Paper and Supplementary Files Only
Use only for small datasets fully represented in the files.
```text
All data supporting the findings of this study are included in the paper, its Supplementary Information, and Source Data files. [Name exact Supplementary Tables when possible.]
```

## 4. Controlled-Access Human/Sensitive Data
```text
The [data type] data supporting this study are not publicly available because [privacy/ethical reason]. A metadata record is available at [Repository/ID]. Qualified researchers may request access from [Committee/Office] at [URL]. Access requires [Ethics Approval/Data-Use Agreement].
```

## 5. Third-Party or Licensed Data
```text
The [data type] data were obtained from [Provider] under licence and are not publicly redistributable. Requests for access should be directed to [Provider/Contact]. Derived data that can be shared are available in [Repository] under [DOI].
```

## 6. Request-Based Access (Last Resort)
```text
The data are not publicly available because [specific justification]. Requests for access may be sent to [Institutional Group/Contact], and will be considered for [eligible purpose] subject to [approval/legal condition].
```

## Audit Questions
- Is the access route durable beyond the corresponding author's email?
- Can a reader tell what each identifier contains?
- Are reused datasets cited in the reference list, not just mentioned?
- Are Source Data files mapped to exact figure panels?
